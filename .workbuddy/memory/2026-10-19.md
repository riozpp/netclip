## 二级域名绑定（qsy.20240225.xyz）

- 账户 zone `20240225.xyz` = `e9d29a183b9c602ebfe007b4e657dfb4`（active，cf NS），同 zone 已有 `pan.20240225.xyz` 指向前一个 worker。
- `POST /accounts/{id}/workers/domains` 用这个 API Token 调用会返回 **10405 Method not allowed for this authentication scheme**；改走声明式 `routes = [{ pattern = "...", custom_domain = true }]` + `wrangler deploy` 即可，Cloudflare 自动建 DNS 记录并签发证书。

## 抖音解析修复（2026-10-19 补）

**根因（实测确认，不是猜测）**
- `/web/api/v2/aweme/iteminfo` 返回 200 但 body 长度为 0 —— 接口已下线数据。
- `/aweme/v1/web/aweme/detail` 返回 403 `Blocked by ArgusSecurityPlugin Uifid Not Found`，需要 `uifid` + `a_bogus` 签名；伪造 `uifid` 头/`UIFID_TEMP` cookie 均无效。
- 分享页 `_ROUTER_DATA.loaderData` 只剩 `video_layout`（空）与 `video_(id)/page`（只有 itemId/serverToken 等壳字段），无 `item_list`。旧代码还会误选 `video_layout`（也以 `video_` 开头）导致取不到数据。

**新链路**：`viaItemInfo`（8s 超时）→ `viaFallback` 公开通道 → `viaSeoPage` SEO 兜底。
- SEO 兜底：蜘蛛 UA（Baiduspider）抓分享页，解析 `<script type="application/ld+json">` 的 `VideoObject`，可稳定拿到标题/description/封面/`PT0H11M53S` 时长/作者/点赞/评论；页面里 `<video>` 标签**没有 src**，拿不到直链。此时返回 `note` 让前端提示「打开原帖」，而不是 422 失败。
- 公开通道默认 `https://api.bugpk.com/api/douyin?url=`（返回 `{code,data:{url,video_backup[],images,music,extra.statistics}}`），可用 `DOUYIN_FALLBACK_API` 覆盖。本机测过的 lolimi / vvhan / qsbye / mxgf / ocr168 / 52vmy / xingzhige / douyin.wtf / tikwm 全部不可用（DNS 或错误码）。
- 加了 5 分钟结果缓存（`caches.default`，只缓存拿到媒体的结果），`src/lib/http.js` 的 `cacheRead/cacheWrite`。

**验证**：线上 `qsy.20240225.xyz` 解析该作品 3–6s 返回 2 条直链（原画 HEVC 95MB / 1280p H.264 56.9MB），`/api/proxy` 206 分段可取、`ftypisom` 有效；浏览器端卡片正常渲染下载按钮。
**注意**：主直链是 HEVC，Windows 默认播放器可能不支持，备用 H.264 版本保留。

## 小红书解析修复（2026-10-19 补）

**根因（实测确认）**
1. 平台识别只登记了 `xhslink.com`，用户分享的短链是 `xhslink.cn` → 直接报 `unsupported_platform`（截图里的「暂不支持该平台」）。
2. 更关键：小红书已对每篇笔记强制 `xsec_token` 校验。浏览器地址栏复制的 `explore/<id>` 一律 307 到 `/404/sec_*`；无 token 直连全是 404。旧代码只提取 noteId 拼 explore 链接，token 丢了，即使域名识别对也必然失败。
3. 页面数据结构变了：PC 端是 `__INITIAL_STATE__.note.noteDetailMap[id].note`，移动分享页是 `__INITIAL_STATE__.noteData.data.noteData`（标题常为空，正文在 `desc`，互动数字段是 `"1.2万"` 这种带单位字符串）。
4. Cloudflare 出口 IP 被小红书针对性封：直连 `discovery/item` 带 token、带 Bytespider 蜘蛛 UA 全部 302。本机住宅 IP 用 Bytespider UA 可以 200 拿到完整 `noteData`（但 CF 上不行，所以 UA 不是解法）。

**实现（`src/resolvers/index.js`）**
- `XHS_SHORT_HOSTS` 加 `xhslink.cn` / `xhslink.net`，`PLATFORMS` 加 `rednote.com`。
- `expandXhsShortLink`：短链逐跳 manual 展开，从跳转 URL 或 `redirectPath`（解码后）里同时取出 noteId 与 `xsec_token`。
- 抓取顺序：直连（蜘蛛 UA，8s）→ `XHS_PROXY`（自备）→ 中转通道（Google 翻译 `xxx.translate.goog`，`gt_auto` 先试）→ 无 token 直连兜底；总预算 26s。
- **Google 翻译中转是唯一在 CF 上跑通的方式**：`https://www-xiaohongshu-com.translate.goog/discovery/item/<id>?xsec_token=…&_x_tr_sl=auto&_x_tr_tl=en&_x_tr_hl=en`，Google 用自己的 IP 抓页面，返回的 HTML 里 `<script>` 内容（含 `__INITIAL_STATE__`）不会被翻译，JSON 可原样提取。
- 图片 URL 统一 http→https；`imageList[].infoList` 优先取 `imageScene: 'H5_DTL'`（1080 原图），退 `WB_DFT` / 首个 / `fileId` 拼 `sns-img-bd.xhscdn.com`。
- 视频多路径：`video.media.stream.{h264,h265,av1,h266}[].masterUrl` → `backupUrls[0]` → `consumer.originVideoKey` 拼 `sns-video-bd.xhscdn.com`；`capa.duration` 是秒、`stream[].duration` 是毫秒，分开判断。
- `parseCount()` 处理 `万/亿` 单位（原实现 `replace(/\D/g,'')` 会把 `1.2万` 变成 12）。
- 4 分钟结果缓存 `xhs:<noteId>`（图片直链按时段签名，缓存不能太长）。
- `ParseError` 新增第 4 个参数 `detail`，`/api/parse` 的错误响应带上 trace（如 `direct:302|gt_auto:200`），便于线上定位是哪一跳断的。

**验证**：线上该笔记 3 次连续解析 2.9–4.4s 成功（标题/作者/点赞 28/评论 44/原图），`/api/proxy` 取回 36KB JPEG（magic ffd8）；Playwright 走完表单提交，卡片、缩略图、下载链接均正常。视频笔记无真实样本，仅做了构造数据单测（`normalizeXhsNote`）。
